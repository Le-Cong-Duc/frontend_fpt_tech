# Frontend quản lý đào tạo

Frontend React + TypeScript + Vite cho hệ thống quản lý khóa học.

## Cài đặt và chạy development

```bash
npm install
npm run dev
```

## Build production

```bash
npm run build
npm run preview
```

API sử dụng base path `/api/v1` và lấy địa chỉ backend từ biến môi trường `VITE_BACKEND_URL`.
